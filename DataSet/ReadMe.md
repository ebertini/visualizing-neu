# Data Handling Requirements

**This folder contains all northeastern faculty and grant data driving this project**

* The data sets will be either in csv or xlsx format
* The data sets will not and should not be uploaded to git
* There are in total 4 data sets provided for this project
* All the datasets require thorough exploration 
* The output of this exploration is the creation of an interactive visualiation which will be used to showcase the history of grant funding in Northeastern
