# Project Requirements

 This is an open ended data visualization project aiming to explore, evaluate, and elucidate Northeastern University's faculty funding and grant history since the last twenty years. 

 * The data set of northeastern funding history is saved in the DataSet folder - review this folder for data handling requirements
 * The output of the data exploration will be the creation of an interactive visualiation which will be used to showcase the history of grant funding in Northeastern
