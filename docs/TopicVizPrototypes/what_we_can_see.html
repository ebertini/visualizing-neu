    Why abstract coverage is so uneven

    How this is computed
    Coverage = grants with usable abstract text ÷ total grants, by agency and by year. NIH's post-2019 collapse (right) is a data-collection artifact, not a funding decline — NIH grant counts hold steady while the evidence behind each topic label thins out. Only a public NIH RePORTER backfill can fix it.

    Where the records go

    How this is computed
    Traces raw abstract records from the upload system through to a grant with usable text; the branch recovers what it can from records that didn't match a grant directly.
